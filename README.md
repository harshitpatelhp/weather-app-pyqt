# PyQt5 Weather App 🌤️

A simple, clean desktop application built in Python using PyQt5 and the OpenWeatherMap REST API.

## Features
- Real-time temperature and weather description lookup.
- Styled user interface using Qt Style Sheets (QSS).
- Graceful API error handling for invalid city names.

## Tech Stack
- Python 3
- PyQt5 (GUI Framework)
- Requests (HTTP Client)

## How to Run
1. Clone this repository:
   ```git clone [https://github.com/YOUR_USERNAME/weather-app-pyqt.git](https://github.com/YOUR_USERNAME/weather-app-pyqt.git)```

2. Install requirements:
   ```pip install PyQt5 requests```
   
3. Get a free API key from OpenWeatherMap.

4. Replace YOUR_API_KEY_HERE in weather_app.py with your key.
5. Run the app:
   ```python weather_app.py```
